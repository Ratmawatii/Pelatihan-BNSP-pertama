# Pelatihan BNSP Pertama

Repository ini merupakan proyek pertama saya dalam mempelajari dasar-dasar pengembangan web sebagai bagian dari kegiatan Pelatihan BNSP.

## Tujuan Proyek
- Mengenal dasar HTML.
- Memahami struktur dokumen HTML.
- Mempelajari penggunaan Git dan GitHub.
- Berlatih mengunggah proyek ke repository GitHub.

## Teknologi yang Digunakan
- HTML
- Visual Studio Code
- Git
- GitHub

## Struktur Proyek
```text
Pelatihan-1/
├── index.html
└── README.md
```

## Status Proyek
Tahap awal pembelajaran pengembangan web.

Dibuat sebagai latihan pertama dalam membangun dan mengelola proyek web menggunakan Git dan GitHub.
